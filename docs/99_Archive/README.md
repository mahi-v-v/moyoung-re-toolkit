# 99 — Archive

Retired or superseded documents are moved **here** rather than deleted — this repo is a portfolio of
the RE journey, so nothing is thrown away.

**Convention**
- When a working doc (`00`–`11`) is wholly replaced, move the old file here and add a dated line below
  pointing to what replaced it. Partial corrections are instead handled **in place** with a dated
  `⚠️` banner (see docs 02, 05, 06) plus a "SUPERSEDED …" note — the correction and the original both
  stay visible.
- The chronological record of *how* conclusions changed lives in the append-only log
  [`../moyoung_reverse_engineering.md`](../moyoung_reverse_engineering.md).

**Currently archived:** _(none)_ — as of the 2026-07-30 documentation pass, every doc was updated in
place; no file was fully superseded. This folder exists so future retirements have a home.
